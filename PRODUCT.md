# Pharma Sales Intelligence

<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Next.js App Router, TypeScript, Tailwind, ECharts; FastAPI, Pandas, OpenPyXL, DuckDB. Windows setup.
## Users
Pharmaceutical sales leaders, finance, brand managers and supply-chain analysts.
## Purpose
Upload compatible Excel workbooks, audit them, explore trusted measures across ten pages, filter and export results, then remove all session data.
## Commitments
The supplied build brief pins a white and neutral-gray executive dashboard with restrained orange emphasis, readable numbers, collapsible navigation and no charts before upload. No invented metrics or causal claims. Derive fiscal periods from invoice dates. Temporary isolated data only.
## Open decisions
Public hosting is not configured; the requested Python application runs locally.
