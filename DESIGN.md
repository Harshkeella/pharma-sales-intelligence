# Pharma Sales Intelligence design

The supplied brief pins the visual direction: a restrained executive analytical workspace. Visitor mode is Operate. The design makes upload, filter context and reconciled measures the primary working surface.

## Shared system

Inter is bundled locally in four weights. The main canvas is #f6f7f9, panels are white, primary text is #232933 and secondary text is #67707c. Borders use #e5e8ec. Orange #c95d18 identifies actions and primary financial results; chart orange is #e47128. Amber denotes review states, not positive performance. No photographic or generated raster assets are used.

The persistent sidebar separates ten analytical views. The header owns audit, export and clear actions. Dataset identity and dates sit beside the page title; filters remain immediately above results. Desktop uses a six-column KPI strip and two-column chart grid. Tablet collapses KPI columns; narrow screens use an icon rail and one-column charts. Explorer alone may scroll horizontally.

## Behavior and accessibility

No metrics or chart canvases render before upload. Missing data has explicit wording. Loading hides previous query results. Native dialogs provide focus containment and Escape dismissal. Native checkboxes and multiple selects support keyboard filtering, while chart selection lists provide a keyboard alternative to canvas clicks. Focus rings, tabular numerals, reduced-motion behavior and visible error text are defined globally.

## Export surface

White landscape layouts remove navigation and menus, retain the selected filter snapshot, and place four main charts below headline measures. PDF pages and image-based widescreen slides carry identical dataset/date metadata.
